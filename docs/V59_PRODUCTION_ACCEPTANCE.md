# V59 P0 生产验收清单

按商户逐站点执行，验收证据不得跨租户复用。

| 阶段 | 操作 | 预期结果 | 证据 |
| --- | --- | --- | --- |
| 配置 | 保存 PayPal Live 凭据和 Live Webhook ID | 后台只显示已配置，不回显 Secret | 集成检查时间 |
| 配置 | 保存已验证域名的 Resend 发件地址 | Resend 检查 Ready | 发件域名状态 |
| 域名 | 通过正式域名访问并检查路由 | DNS、SSL、后台域名状态正常 | 正式 URL |
| 支付 | 创建一笔小额真实订单 | 金额由服务端计算，Capture 后才显示已支付 | 订单号、Capture ID |
| Webhook | 投递并重放同一事件 | 只处理一次，不重复扣库存或发邮件 | Webhook 事件记录 |
| 邮件 | 检查付款邮件 | 正式发件人送达，通知状态为已发送 | 通知记录 |
| 发货 | 填写物流单号并标记发货 | 客户订单页显示物流信息，发货邮件送达 | 订单时间线 |
| 退款 | 执行部分或全额退款 | 金额准确，重复请求幂等，库存按选择处理一次 | Refund ID、库存流水 |
| 超时 | 创建未付款订单并等待回收 | 订单过期，库存和优惠券被释放 | 恢复任务记录 |
| 邮件失败 | 制造可恢复失败后重试 | 失败可追踪，重试不重复发送 | 通知重试记录 |
| 备份 | 创建备份并运行恢复演练 | R2 备份、校验和、租户和关键表全部通过 | Backup ID、校验时间 |
| 发布 | 提交、审批并发布 | 未完成项目会阻断；通过后生成版本 | 发布记录 |
| 回滚 | 对测试版本执行回滚 | 生成新的审计版本，站点恢复稳定内容 | 回滚版本号 |

最终结果：所有必填项通过、无未解决 P0/P1、后台无失败运营事件，方可将商户标记为正式上线。
